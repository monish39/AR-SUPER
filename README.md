# AR SUPER - Disaster Response Simulator

An Augmented Reality (AR) / Virtual Reality disaster response and mass-casualty incident simulation built in Unity.

## Features
- **START Triage System**: Simple Triage and Rapid Treatment simulation with dynamic patient classification.
- **FLIR Thermal Vision Controller**: Tactical thermal vision simulation for hazard detection and victim search.
- **AI EMS Stretcher Team**: Autonomous responder navigation and casualty evacuation routines.
- **Tactical Radio Comms & Audio FX**: Immersive emergency comms and vitals monitoring soundscapes.
- **Physiological Simulations**: Realistic victim chest breathing animations, pulse rates, and vitals.

## Project Structure
- `Assets/DisasterResponseSimulator`: Core scripts, tools, and simulations.
- `Packages`: Unity package manifests and dependencies.
- `ProjectSettings`: Engine configuration and input mappings.

## Prerequisites
- Unity Editor (version compatible with project settings)
- XR / AR foundation packages (configured in package manifests)
